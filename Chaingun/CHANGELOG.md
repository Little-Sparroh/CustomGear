# Changelog

## 1.0.0

- Initial release (Phase 0 + 1)
- Registers **Chaingun** primary (`api=chaingun`, id `93100`) by cloning vanilla **MiniCannon** (Gunship Cannon)
- Kinetic retune via `ChaingunBalance` (modest per-bullet damage, large mag, hungry reserves, mid–long falloff)
- Always-on light spool: RoF ramps while holding M1, decays on release
- Soft move penalty at high spool
- ADS disabled on baseline
- No upgrade pool yet (Hellstorm / Auto Turret / Warthog paths come later)
- Persistence + SpawnGear stamp so equip/loadout survive relaunch
